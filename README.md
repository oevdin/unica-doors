# UNICA Doors — заявки на двери и комплектующие

Веб-приложение (работает и с телефона) для приёма заявок: межкомнатные и
металлические двери, коробки, наличники, доборы, фурнитура, пороги.

## Что умеет

- Каталог по разделам: двери отдельно, комплектующие отдельно.
- У товара есть **варианты** (цвет, размер, остекление, открывание) и
  **единица** (шт, компл., пог. м).
- Для межкомнатной двери — блок **«Собрать комплект»**: коробка, наличники,
  доборы, петли, ручка, защёлка. Цвет комплектующих подставляется как у двери.
- Заявка, контрагенты, список заявок со статусами, админка (разделы, товары,
  пользователи).

Сейчас в каталоге **демо-товары** со схематичными картинками — их заменят
реальные данные (`server/seed_data.json` или через раздел «Админ»).

## Запуск на компьютере

```
npm install
npm run seed
npm start
```

Откройте http://localhost:3000, логин `admin`, пароль `123456`.

## Формат данных каталога (`server/seed_data.json`)

```json
{
  "categories": [
    { "name": "Межкомнатные двери — экошпон", "slug": "interior-ecoshpon", "icon": "door_interior", "sort_order": 0 }
  ],
  "products": [
    {
      "category_slug": "interior-ecoshpon",
      "name": "Дверь «Модерн-0» глухая",
      "price": 4900,
      "unit": "шт",
      "photo": "/img/demo/door-flat-white.svg",
      "description": "…",
      "options": { "Цвет": ["Белый", "Капучино"], "Размер": ["700×2000", "800×2000"] }
    }
  ]
}
```

Блок «Собрать комплект» привязан к slug разделов (`frames`, `casings`,
`extensions`, `hardware`, `thresholds`) — правила в `KIT_RULES` в `public/app.js`.

## Размещение на Render

В репозитории есть `render.yaml`: на https://dashboard.render.com →
**New → Blueprint** → выбрать этот репозиторий → задать `SEED_ADMIN_PASSWORD`
→ **Apply**. Для постоянного хранения базы и фото нужен платный тариф с диском
(переменная `DATA_DIR`).
