# UNICA — продажи, касса, склад и отчёты для магазина дверей

Веб-приложение для работы с телефона и компьютера: продавец оформляет продажу за пару касаний,
владелец видит деньги, остатки, долги и прибыль.

## Разделы

- **Продажа** — поиск и разделы, товар одним касанием; варианты (цвет, размер, остекление);
  к межкомнатной двери сразу предлагается всё для установки (коробка, наличники, доборы, фурнитура).
  Оформление: скидка в сомах или %, оплата наличными, переводом, частями или в долг,
  покупатель по имени/телефону (клиент находится или создаётся сам).
- **Чеки** — история продаж, долги, приём оплаты долга, отмена продажи (товар возвращается на склад,
  деньги — расходом «Возврат покупателю»). Накладная: WhatsApp картинкой, печать A4, чек 58/80 мм.
- **Касса** — остатки по счетам (наличные, банк, можно добавить свои), приход, расход по статьям,
  перевод между счетами, журнал операций.
- **Склад** — товары с остатками, себестоимостью и наценкой, «заканчиваются», инвентаризация,
  приход товара от поставщика (себестоимость пересчитывается по средней), долги поставщикам.
- **Клиенты и поставщики** — карточка, история покупок/приходов, долги, звонок и WhatsApp.
- **Отчёты** (владелец) — выручка → себестоимость → **валовая прибыль** → расходы → **чистая прибыль**;
  маржа, наценка, средний чек, скидки, сравнение с прошлым периодом; графики по дням и деньгам;
  расходы по статьям; ABC-анализ товаров; разделы; продавцы; часы и дни продаж; долги;
  отчёт о прибылях и убытках с печатью.

Роли: **владелец** видит всё; **продавец** — продажу, свои чеки, свои операции кассы и клиентов,
без себестоимости и прибыли.

## Запуск

```
npm install
npm start
```

Откройте http://localhost:3000 — логин `admin`, пароль `123456` (или из `SEED_ADMIN_PASSWORD`).
При первом запуске загружается демо-каталог дверей (`server/catalog_demo.json`).

«Ещё → Демо-данные» добавляет месяц примерных продаж, приходов и расходов, чтобы посмотреть отчёты;
«Ещё → Начать с нуля» удаляет все операции, оставляя каталог.

## Размещение на Render

`render.yaml` в репозитории: **New → Blueprint** → этот репозиторий → задать `SEED_ADMIN_PASSWORD` → **Apply**.
На бесплатном тарифе база стирается при перезапуске сервера. Для работы нужен тариф с диском:
добавьте диск (например, `/var/data`) и переменную `DATA_DIR=/var/data`.

## Устройство

- `server/` — Node.js + Express + SQLite (better-sqlite3). Деньги — в целых сомах, время — UTC,
  отчёты считаются по местному времени (`TZ_OFFSET_MINUTES`, по умолчанию 360 — Бишкек).
- `public/` — одностраничное приложение без сборки: `js/core.js` (ядро), `pos.js`, `docs.js`,
  `cash.js`, `stock.js`, `contacts.js`, `reports.js`, `admin.js`; стили — `css/app.css`.
